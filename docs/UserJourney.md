# User Journey

## User Journey 1 - Predecir la calidad del aire antes de salir a correr
## Persona

Daniel es un estudiante universitario de Granada que sale a correr varias veces por semana. 
Sus horarios cambian según las clases y las actividades que tenga durante el día.

## Contexto

Un día termina sus clases por la tarde y tiene previsto salir a correr a las 19:00. 
Le preocupa realizar ejercicio intenso cuando las concentraciones de contaminantes en el aire son elevadas.

## Problema

Daniel conoce la hora a la que puede salir, pero desconoce qué calidad del aire habrá en ese momento. 
Consultar las mediciones actuales no le permite saber cuáles serán las condiciones dentro de unas horas.

## Necesidad

Quiere conocer una predicción de la calidad del aire para una hora futura, 
que le indique si las condiciones serán favorables o desfavorables para practicar deporte.

## Recorrido

1. Daniel decide salir a correr a las 19:00.
2. Antes de salir, consulta la predicción de calidad del aire para esa hora.
3. El sistema utiliza mediciones anteriores de contaminantes para estimar las condiciones de la hora solicitada.
4. Daniel recibe una valoración prevista de la calidad del aire, o una indicación de que no hay datos suficientes para estimarla.
5. Utiliza esa información para decidir si mantiene su horario o considera cambiarlo.

## User Journey 2 - Elegir entre diferentes horas para salir a caminar
## Persona

José tiene 35 años, vive en Granada y sale a caminar habitualmente. Tiene sensibilidad a la contaminación atmosférica 
y procura evitar las horas en las que las condiciones del aire pueden ser desfavorables.

## Contexto

José tiene tiempo libre entre las 18:00 y las 21:00. 
Quiere caminar durante una hora, pero no sabe cuál de las horas disponibles tendrá mejores condiciones.

## Problema

Aunque puede escoger el horario, no conoce de antemano cómo variará la calidad del aire durante la tarde. 
Necesita comparar las condiciones previstas de varias horas antes de organizar su salida.

## Necesidad

Quiere comparar las predicciones de calidad del aire de diferentes horas para identificar 
la franja que previsiblemente tendrá las condiciones más favorables.

## Recorrido

1. José decide salir a caminar esa tarde.
2. Consulta las predicciones de calidad del aire para las 18:00, 19:00 y 20:00.
3. El sistema estima la calidad del aire de cada hora a partir de los datos disponibles.
4. Compara las valoraciones previstas e identifica la hora con mejores condiciones.
5. José consulta el resultado y decide cuándo salir. Si las condiciones previstas son desfavorables, puede aplazar su actividad.
